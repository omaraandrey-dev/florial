## Решение владельца — единственная AI-модель для растений

- Единственный основной AI-провайдер рабочего сценария подготовки карточек растений в Manager — Google Gemini.
- Не использовать Cloudflare Workers AI или другие модели как основной/резервный AI-провайдер этого сценария.
- Owner, Manager и Seller должны иметь одинаковую возможность запускать Google Gemini Photo/Text, получать результат и применять ботанические данные. Не ограничивать ботанические поля ролью Owner.
- Обязательные поля каждого нового растения:
  - `plantCare.light` — освещённость;
  - `plantCare.waterNeeds` — потребность в воде;
  - `plantCare.minWinterTempC` — минимальная зимняя температура;
  - `plantCare.adultHeightCm` — высота взрослого растения;
  - `plantCare.foliageType` — тип листвы;
  - `plantCare.floweringSeason` — сезон цветения;
  - `plantCare.plantingSeason` — сезон посадки;
  - `plantCare.blackSeaCoast` — пригодность для Черноморского побережья;
  - `careGuide` — руководство по уходу.
- Не выдумывать недостоверные характеристики. Если точное значение неизвестно, использовать null/пустое значение либо `needsVerification` в рамках схемы. `blackSeaCoast` остаётся `needsVerification` до подтверждения.
- Не смешивать взрослую высоту растения с продажной высотой конкретного экземпляра в `saleVariants[].saleHeightCm`.
- Не генерировать AI коммерческие данные: SKU, продажные размеры, объём контейнера, цены, остатки и статус наличия.
- Актуальная проверка кода 11.11.2026 выявила owner-only условия в `src/manager/PlantCatalogManager.tsx`, которые исключают `plantCare` и `careGuide` из применения/сохранения для Manager и Seller. Одной D1 permission update недостаточно. Устранение ограничения требует изменения кода и отдельного согласования владельца.
- Production D1 на момент проверки: Owner 1, Manager 1, Seller 0; у Manager уже `canCreatePlant=true`; отдельного `canUseGoogleAI` permission key нет. Не менять другие права сотрудника ради AI-доступа.
- До изменения кода считать Google AI endpoint доступным ролям Owner/Manager/Seller, но полное сохранение ботанических полей всеми ролями — НЕ ВЫПОЛНЕНО.
- Изменения документации сами по себе не означают, что runtime-код или Production D1 были изменены.
