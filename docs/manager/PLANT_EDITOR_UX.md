# Manager — UX работы с растениями

Дата: 2026-11-21  
Статус: реализовано в рабочей ветке; проверки CI и Production deployment ожидаются.

## Разделение интерфейса по ролям

### Seller и Manager
Рабочая форма должна содержать только сведения, необходимые для повседневной работы с карточкой:
- название растения;
- фотографии и выбор главной фотографии;
- тип и категории;
- варианты продажи: модель/размер, высота, объём контейнера;
- цена, старая цена, наличие и количество — только в рамках существующих прав;
- краткое описание и описание на болгарском;
- AI-помощник заполнения по названию/фотографии и существующая проверка дубликатов.

URL/slug не вводится вручную сотрудником: он формируется автоматически из названия. Поля переводов RU/EN, SEO (H1, Meta Title, Meta Description), ботанические характеристики и рекомендации по уходу остаются Owner-only. Сотрудник не должен видеть эти блоки и не должен заполнять их пустыми значениями.

### Owner
Owner сохраняет полный доступ к дополнительным полям:
- SKU и ручная корректировка URL/slug;
- переводы BG/RU/EN;
- SEO;
- ботанические характеристики, оценка пригодности для Черноморского побережья и уход;
- библиотека изображений и ALT.

## UX изменения редактора
- Добавлена быстрая навигация к основным разделам; Owner видит дополнительные ссылки SEO и характеристики/уход.
- Длинные блоки описания, SEO и ухода свёрнуты по умолчанию. Фотографии, основная информация и размеры/цены остаются сразу доступны для рабочего сценария.
- Seller и Manager видят короткую подсказку о границах их работы и автоматическом URL.
- При выходе через кнопку «Назад» показывается подтверждение, если форма или фотографии изменены.
- При попытке закрыть/перезагрузить вкладку браузер показывает стандартное предупреждение о несохранённых изменениях.

## Неизменяемые границы
- API, валидация сервера, ролевые permissions, Sanity документы/схемы и D1 не изменялись.
- Сохранены существующие AI proof, duplicate picker, optimistic revision conflict check и idempotency.
- Не менялись глобальная оболочка Manager, Header, меню, Footer или маршрутизация.
