# Florial blog migration

## Inventory
- Source: https://www.drop.od.ua/bg/blog and linked Bulgarian archive/category pages.
- 19 distinct Bulgarian articles have been inventoried with publication dates, titles, original covers, and image references.
- The raw Markdown snapshots in `source/` are immutable audit copies. They retain the original source wording and URLs for traceability.
- `source-inventory.json` contains article titles in BG/RU/EN, dates, source URLs, cover URLs, and body-image references.
- `image-manifest.json` contains the image audit, source alt text, suggested Bulgarian alt text, and video-thumbnail separation.
- `editorial-change-report.json` records legacy Drop links, contacts, locality references, and price mentions.
- `known-cover-refs.json` records the verified cover assets already uploaded to Sanity production.
- `prepare-from-source.mjs` creates Portable Text from the source snapshots, uploads unique inline images to Sanity, removes legacy site navigation, maps old Drop article links to Florial routes, replaces the old Ukraine phone number, and writes `prepared-posts.json`.
- `import-blog-posts.mjs` validates all posts and performs an idempotent import. It is a dry run unless `--write` is supplied; production writes require `--confirm-production-write`. Use `--publish` only when publishing is explicitly authorized.
- `asset-upload-report.json` is generated by the migration workflow and records successful/failed source image uploads.

## Editorial policy authorized by the owner
- Keep source publication dates and factual details.
- Replace Drop-specific links with Florial pages or relevant internal blog routes; replace old contact details with Florial contact details.
- The rose article's original price of 25 лв. is converted to 12,50 € using the owner's rate of 2 BGN = 1 EUR.
- Other historical price values are retained exactly as found in the source, as explicitly authorized by the owner; no additional price approvals are required.
- Bulgarian is the complete body language at launch. Russian and English titles, summaries, SEO titles/descriptions, and cover alt texts are provided; where full translated body text is absent, the site falls back to Bulgarian and marks that language version noindex to avoid indexing duplicate-language content. This fallback is intentional and should be replaced with full translations in a later editorial pass.
- YouTube thumbnails are not uploaded as photos. Recognized image blocks are migrated as Sanity image assets; any individual failed non-cover image upload is logged and that image is omitted rather than broken.

## Deployment flow
1. GitHub Actions installs dependencies and runs website build/lint plus Studio build.
2. After validation, the workflow deploys the schema to the existing `florial-admin` and `plants` workspaces using the repository's Studio source, then deploys the existing Studio app configured by `studio/sanity.cli.ts`.
3. The workflow prepares content and image assets, runs the migration validator, then imports and publishes the 19 articles into Sanity production.
4. The workflow requires the GitHub Actions secret `SANITY_AUTH_TOKEN`. No token is committed to the repository. If the secret is missing or lacks permissions, schema deployment and publication stop without a success claim.

The workflow does not create a new managed Sanity Studio, does not write to Supabase, and does not alter order logic.
