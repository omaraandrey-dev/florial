# Журнал изменений Florial

## 2026-10-22 — Усиление безопасности репозитория и Supabase

- Удалён `.env` из текущей ветки `main`; добавлен безопасный шаблон `.env.example`.
- Обновлён `.gitignore`: рабочие `.env*` исключены из Git, кроме `.env.example`.
- В Supabase удалена политика публичного создания заказов; роли `anon` и `authenticated` больше не имеют прав чтения/записи таблицы `orders`.
- Для `products` и `product_categories` публичным ролям оставлено только чтение; фильтрация активных записей по-прежнему обеспечивается RLS.
- Проверено: RLS включён на трёх таблицах; `service_role` сохраняет право вставки заказов, публичные роли его не имеют.
- Проверка Supabase Security Advisors после изменения показала информационное сообщение `RLS Enabled No Policy` для `orders`. Это ожидаемо: клиентские политики удалены намеренно, а серверная функция работает с серверным ключом.
- Добавлен файл миграции `supabase/migrations/20261022003000_harden_public_table_privileges.sql`, фиксирующий применённые изменения.
- Ограничение аудита: история Git до удаления `.env`, настройки Cloudflare/Sanity и полный end-to-end заказ отдельно не проверены.
