# Журнал изменений Florial

## 2026-10-22 — Техническое SEO: robots.txt и динамический sitemap.xml

- Добавлен `public/robots.txt` с разрешением обхода публичных страниц (`User-agent: *`, `Allow: /`) и ссылкой на `https://florial-bg.com/sitemap.xml`.
- Добавлена Cloudflare Pages Function `functions/sitemap.xml.ts`, которая динамически получает активные услуги, товары и категории из публичных Sanity datasets `production` и `plants`.
- В карту включаются главная, контакты, страницы услуг, категории и карточки активных товаров; документы с `seo.noIndex = true` пропускаются там, где это поле предусмотрено.
- URL формируются на основном домене `https://florial-bg.com`; языковые query-параметры не дублируются в карте, поскольку canonical URL сайта использует основной путь.
- Для карты установлен короткий CDN-кэш (5 минут), чтобы новые публикации Sanity появлялись без ручного редактирования XML после истечения кэша.
- Публикация и production-проверка sitemap выполняются отдельно; наличие исходного файла само по себе не считается подтверждением доступности endpoint.

## 2026-10-22 — Усиление безопасности репозитория и Supabase

- Удалён `.env` из текущей ветки `main`; добавлен безопасный шаблон `.env.example`.
- Обновлён `.gitignore`: рабочие `.env*` исключены из Git, кроме `.env.example`.
- В Supabase удалена политика публичного создания заказов; роли `anon` и `authenticated` больше не имеют прав чтения/записи таблицы `orders`.
- Для `products` и `product_categories` публичным ролям оставлено только чтение; фильтрация активных записей по-прежнему обеспечивается RLS.
- Проверено: RLS включён на трёх таблицах; `service_role` сохраняет право вставки заказов, публичные роли его не имеют.
- Проверка Supabase Security Advisors после изменения показала информационное сообщение `RLS Enabled No Policy` для `orders`. Это ожидаемо: клиентские политики удалены намеренно, а серверная функция работает с серверным ключом.
- Добавлен файл миграции `supabase/migrations/20261022003000_harden_public_table_privileges.sql`, фиксирующий применённые изменения.
- Ограничение аудита: история Git до удаления `.env`, настройки Cloudflare/Sanity и полный end-to-end заказ отдельно не проверены.

## 2026-10-22 — Исправление вложенных URL и навигационных ссылок

- Удалён относительный `base: './'` из Vite; сборка использует стандартный корневой путь для ресурсов на основном домене.
- Добавлен общий обработчик внутренних ссылок: обычный клик сохраняет SPA-переход, а Ctrl/Cmd/Shift-клик и открытие ссылки через контекстное меню оставляются браузеру.
- Карточки услуг и категорий на главной, пункты меню услуг и категорий, хлебные крошки, карточки товаров в категориях и поиске, а также совместимые товары переведены на настоящие ссылки с `href`.
- Правило Cloudflare Pages `public/_redirects` сохранено без изменений.
- Проверено по Cloudflare Pages: production build и deploy для текущей версии завершились успешно. Прямое открытие и загрузка вложенных URL проверены для страницы услуги, категории оборудования, категории растений и карточки товара; сервер отвечает HTTP 200.
- Контекстное меню/долгое нажатие в реальном браузере пользователя требует финальной проверки на устройстве.
